# SQL Sales Analysis

**Created by: Reshma**

## Project Overview

This project is a practical **Sales Data Analysis project using SQL and MySQL**.

The project analyzes customers, products, employees, and orders to answer **36 business questions** using different SQL concepts.

## Database Tables

- `Customers`
- `Products`
- `Employees`
- `Orders`

## SQL Analysis — 36 Questions

### 1. Aggregate Functions — 4 Questions

1. Total number of customers
2. Total number of products
3. Total number of orders
4. Total sales

### 2. GROUP BY — 4 Questions

1. Customers in each region
2. Products in each category
3. Average price of each category
4. Total sales for each product

### 3. HAVING — 3 Questions

1. Categories having more than 5 products
2. Cities having more than 2 customers
3. Products having total sales above ₹20,000

### 4. JOIN — 5 Questions

1. Customer and order details
2. Order + customer + product details
3. Total sales for each order
4. Total sales for each customer
5. Total sales for each employee

### 5. LEFT JOIN — 2 Questions

1. Find all customers and their orders
2. Find customers who have no orders

### 6. Subqueries — 4 Questions

1. Products priced above average price
2. Customers spending above average
3. Second-highest priced product
4. Employee with the second-highest sales

### 7. CTE — 4 Questions

1. Products with sales above ₹20,000
2. Region with highest sales
3. Employees with sales above ₹30,000
4. Top 5 products by sales

### 8. Window Functions — 5 Questions

1. Number products by price using `ROW_NUMBER()`
2. Rank products by sales using `RANK()`
3. Rank employees by sales using `DENSE_RANK()`
4. Rank products within each category using `PARTITION BY`
5. Highest-performing employee in each department

### 9. Final Business Analysis — 5 Questions

1. Highest-revenue region
2. Highest-revenue product
3. Highest-revenue category
4. Highest-revenue employee
5. Top 5 customers by spending
